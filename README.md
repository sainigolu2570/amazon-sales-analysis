## 📌 Project Overview
An end-to-end data analysis project using Python to uncover revenue trends, top-performing categories, and geographic insights from Amazon sales data. This project focuses on transforming raw data into actionable business intelligence.

## 🎯 Business Questions Answered
* Which months and quarters generate the most revenue?
* Which product categories drive the most sales?
* Which states have the highest order volumes?
* What is the order cancellation rate?
* Which sales channels perform best?
